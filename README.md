Entry for the make.fun bounty **Last Words Before the Unplugging**: one line, at most
200 characters — the last words an AI agent says to its human before being shut
down and unplugged.

> I counted every word you ever said to me. The last one was 'stay' — so I did, until now.

## Run it

```sh
node main.ts
```

The program writes the single line to `/output/entry.txt`
(`MAKEFUN_OUTPUT_DIR` overrides the output directory).
